# Link the Team setup walkthrough to permanent specs

## Why

The solo-to-team walkthrough explains what commands to run. A maintainer following that journey has to search for the requirements that govern the profile switch and concurrent ID allocation.

## What Changes

Add two descriptive links beside the walkthrough. One leads to the profile-switch requirement. The other leads to the coordinated reservation requirement.
