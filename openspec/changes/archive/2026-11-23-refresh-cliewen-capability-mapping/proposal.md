# Refresh the Cliewen capability mapping

## Why

The existing comparison predates Cliewen 0.33.1 and describes some shipped behavior as planned. Maintainers need a versioned reference when deciding which practices to revisit.

## What Changes

Update the existing mapping with all Cliewen capability areas, supplementary CLI behavior, and links to the corresponding OpenSpec-based behavior. Record the six follow-up ideas. Update the guide so readers can compare their installed CLI with the version published on npm and see how to preview resource changes.

### New Capabilities

None.

### Modified Capabilities

None.

## Impact

Updates the [practice mapping](../../../../docs/cliewen-mapping.md) for maintainers and the [update guide](../../../../docs/guide/updating.md) for adopting projects.
