# Show which files each schema uses

## Why

Readers can choose a schema in the guide, but the overview omits exact filenames. That makes it easy to mistake the absence of `tasks.md` in Discovery for incomplete work.

## What Changes

Add the filenames to the existing schema table. Explain when agents write the files, how Combined uses its decision for design, and how changes with skipped specs handle tasks. Use an example for each schema to connect file names to their purpose.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None.

## Impact

Updates the [guide's schema overview](../../../../docs/guide/index.md#choose-a-schema-for-the-uncertainty).
