# Prepare 0.3.0

Version 0.3.0 is a local candidate. npm still serves 0.2.0 as latest. All five [roadmap items](../../plan.md) have been archived.

## What changes for projects

- Work in a repository-local OpenSpec 2 project while retaining existing native skills and authored changes. Cliewen also supports OpenSpec 1.15.0 and later for the documented repository-local paths.
- Coordinate acceptance IDs through Git when more than one branch, clone, or agent allocates them. Local allocation remains the default.
- Use guided context selection to find current project records. Explicit off stays off.
- Check local links, optional frontmatter, and Mermaid syntax with `docs check`. Checks are advisory by default and independently configurable.
- Use `ci inspect` to see whether GitHub requires the checks you select. It reports incomplete access and visible bypass exceptions. Inspection needs a configured repository and expected checks.

Upgrade to Node 22.12+ before installing 0.3.0. The candidate refreshes resources installed by published 0.1.0 or 0.2.0, keeping configuration, authored content, and reserved acceptance IDs. [Update guide](../guide/updating.md)
