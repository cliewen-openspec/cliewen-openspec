# Prepare Cliewen for OpenSpec 0.4.0

The planned work is archived. The [0.4.0 changelog](../../CHANGELOG.md#040-2026-11-23) describes capability evidence, setup profiles, scope review, and implementation readiness.

The package supports updates from 0.1.0 through 0.4.0. The minimums remain Node 22.12 and OpenSpec 1.15.0. The package is for repository-local OpenSpec projects.

## Candidate evidence

The original local npm tarball SHA-256 was `c05f94e74295bb6eb4f38dcf9e79d73a487309663cd7195cdb3df582f9a3a8d7`. A fresh project installed it with OpenSpec 2.1.1, registered all three Cliewen schemas, and saved the solo profile. Native initialization initially used OpenSpec's global skill default. A second run with `--scope project` wrote ten skills inside the test project. Repeating Cliewen init with the solo profile required no writes.

Strict OpenSpec validation passed for all 18 permanent specs. The guide build checked 13 pages, 550 local links, and five diagrams. Desktop and mobile browser checks passed.

The local Windows and Node 24 suite passed 185 of 187 tests on the first run, including the published 0.3.0 upgrade and the existing 0.1.0 and 0.2.0 upgrade paths. The two failures used the old version in the CSV guide or treated 0.4.0 as a future version. Both passed on targeted reruns after correction. Those edits are outside the npm package, and repacking reproduced the original SHA-256.

The readiness trial used two fresh Claude Code sessions with Opus 5.5. One paused an ambiguous request and recorded the blocking question. The next resumed from the simulated answered ticket without chat history. The release candidate retains the reviewed guidance and defaults. Live ticket updates and other agent runtimes were outside that trial. [Readiness trial](../../openspec/changes/archive/2026-11-22-assess-implementation-readiness/tasks.md#verification)

The revised candidate SHA-256 is `e5818a919c39bba914cc5fb60af273dadfadb850689aa6e063d81d90f1da2623`. Only the packaged planning instructions changed. Claude Code resumed from an answered ticket with precise references, preserved the unrelated requirements, and used the recorded answer without reposting it.

[Hosted package CI](https://github.com/cliewen-openspec/cliewen-openspec/actions/runs/45247016933) passed on Windows and Linux with Node 22.12.0 and 24 for source `2936994`. The [guide build and browser checks](https://github.com/cliewen-openspec/cliewen-openspec/actions/runs/45247017472) passed on the same commit. The owner approved release on November 23, 2026.

The publication tarball SHA-256 is `2fb30b0ac5b02ee09d6d73ed20f9fe3dd3fb1bb9e9a7d7340cf078279e9653b6`. Comparing all 93 files with the hosted CI candidate found only the release heading change in `CHANGELOG.md`. npm published version 0.4.0 under `latest` on November 23, 2026.
