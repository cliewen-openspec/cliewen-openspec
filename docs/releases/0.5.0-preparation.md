# 0.5.0 release candidate

The local candidate is based on source commit `f092ed43c57fbbd7330e4e47c18fcddce18c659f`. The 96-file npm tarball has SHA-256 `aa4fe717ad45b75164c53f21fbe8b7f6e2728b449abbea6e7f63f74213fd674d`. Release notes remain under Unreleased until publication.

## Upgrade and agent checks

Clean projects with the published 0.4.0 package and OpenSpec 2.1.1 installed the candidate. Windows previewed and applied the update. On Ubuntu under WSL, preview ran inside the Codex workspace sandbox and apply ran on the host. Both previews listed the closure reference and ownership manifest as the only managed writes, apply wrote those files, and the fixture test passed. A second Windows preview reported no remaining writes or deletes.

Claude Code and OpenCode previously completed the upgrade and release-note workflow on the qualification package. Codex completed the release-note workflow after host apply. All three used the same installed closure text as this candidate. The compatibility fix and the split preview and apply sequence were verified separately. Applying from inside the tested Codex workspace sandbox remains blocked by its protection of the Git directory.
